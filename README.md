# 神学（哲学）者辞典

古代から現代までの神学者を、**名前・キーワードから**引いたり、**神学的テーマから**探したりできる静的Webアプリです。
HTML / CSS / JavaScript だけで動くので、GitHub Pages でそのまま公開できます。

## 機能

- **名前で探す**：名前・原語名・著作名・キーワードで検索（カタカナ／ひらがな、全角／半角の違いは吸収）。スペース区切りで AND 検索（例：`解放 カトリック`）
- **教派・時代で絞り込み**：古代／中世／宗教改革／近世／近代／現代、カトリック・ルター派・改革派など（教派の選択欄は検索欄のすぐ下）
- **分野で絞り込み**：聖書学／組織神学／歴史神学／実践神学／哲学／その他（宗教学・文学・社会科学など）。複数の分野に入る人もいます
- **出身国で絞り込み**：日本・ドイツ・アメリカなど人数の多い国は国ごと、少ない国は「アフリカ」「中南米」「東欧・ロシア」などの地域ボタンにまとめて表示（まとめ方は `js/data.js` の `COUNTRY_GROUPS` で変更可）。古代・中世の人物は「北アフリカ」「トルコ（小アジア）」など、生まれた地域を現在の国名・地域名で大まかに示しています
- **テーマで探す**：三位一体論、義認論、終末論、解放の神学など約40テーマから一覧
- **年表で見る**：時代ごとに生年順で表示。世界史・教会史・日本史の主な出来事（十字軍、宗教改革、明治維新、世界大戦など）も年代順に挿入。論争・会議と神学教育機関の創立も並び、押すとそれぞれの解説へ移動（`js/events.js` で追加・修正可、種類ごとに表示を切り替え可能）
- **詳細表示**：概要・生涯・思想のポイント・影響と評価・批判と論争（主な批判者へのリンクつき）・主著・テーマ・キーワード・関連する神学者（テーマが近い人物を自動表示）
- **現代神学略解**：バルト以降の神学の潮流（弁証法神学、実存論的神学、希望の神学、解放の神学、フェミニスト神学、ポストリベラル神学など約30）を時代の地図と解説で整理。解説から各神学者へ、神学者の詳細画面から関わる潮流へ相互にリンク（`js/streams.js` で追加・修正可）
- **神学教育機関**：近代以降の主要な大学・神学校（ベルリン、テュービンゲン、バーゼル、ユニオン、プリンストン、同志社、東京神学大学など約45）の解説と、そこで教え学んだ神学者の一覧。神学者の詳細画面からも関わった機関へ移動でき、相互に検索可能（`js/institutions.js` で追加・修正可）
- **論争・会議**：ニカイア、カルケドン、トリエント、第二バチカンなどの公会議と、ペラギウス論争、聖餐論争、ドルト会議、自然神学論争など、キリスト教の歴史上の論争・会議（約50項目）を時代順に解説し、関わった神学者と相互にリンク。時代・種類で絞り込みや検索ができます（`js/debates.js` で追加・修正可）
- **メモ**：人物の詳細画面の「メモ」欄に自由に書き込め、自動で保存（この端末のブラウザ内のみ）。「メモ」タブで一覧・検索・並べ替え・その場で編集・削除ができ、テキストでの書き出しやバックアップ（JSON）の保存・読み込みで別の端末にも移せます。メモの内容は名前検索の対象にもなり、一覧のカードには「メモ」の印が付きます。Googleアカウントでログインすると、同じアカウントのどの端末からでも同じメモを読み書きできます（下の「メモの同期の設定」を参照）
- **読み上げ**：画面下部のボタンで、表示している画面（人物の詳細画面が開いていればその内容）を、見えている位置から順に読み上げ。文章をタップ（クリック）すると、そこから読み上げます（読み上げ中ならその段落へ移動、止まっているときは印を付けて ▶ でそこから開始）。読んでいる箇所に色が付きます。一時停止・停止・速さ（×0.8〜×1.5）の切り替えができます（ブラウザの音声合成機能を使用）
- **詳解ページ**：主要な神学者（アウグスティヌス、ルター、カルヴァン、バルト、ボンヘッファー、内村鑑三、北森嘉蔵、コーン、C・S・ルイス、賀川豊彦など39人）について、その神学・思想を章立てでくわしく解説するページ。人物の詳細画面のボタンから開けます（一覧では「詳解」の印つき。`js/essays.js` で追加・修正可）
- **クイズ**：説明・キーワード・主著・時代・教派・生涯から神学者を当てる4択クイズ。出題範囲と問題数を選べ、連続正解ボーナス・称号・自己ベスト記録つき（問題はデータから自動生成）
- 詳細ページには `index.html#luther` のようなURLが付くので、特定の神学者へのリンクを共有できます

## ファイル構成

```

css/style.css   デザイン

js/critiques.js 一人ひとりの神学に対する批判点と批判者
js/events.js    年表に挿入する歴史の出来事
js/streams.js   現代神学略解（神学の潮流の解説）
js/institutions.js 神学教育機関と神学者の関わり
js/debates.js   論争・会議（関わった神学者とのリンク）
js/essays.js    詳解ページ（主要な神学者の神学・思想のくわしい解説）
js/app.js       検索・表示の仕組み
manifest.webmanifest / icons/   ホーム画面に追加したときのアイコンと名前
js/quiz.js      クイズ
js/tts.js       画面下部の読み上げボタン
js/notes.js     神学者ごとのメモ（この端末のブラウザに保存）
js/sync.js      メモの同期（Googleアカウント／Firebase）
js/firebase-config.js  同期の設定値（Firebase のウェブアプリの設定）
```

## 神学者を追加・修正するには

`js/data.js` を開き、既存の項目を1つコピーして書き換えます。ファイル冒頭に各欄の説明があります。

- `id` は半角英数字で、他と重ならないもの
- `era` は `ancient` `medieval` `reformation` `early-modern` `modern` `contemporary` のいずれか
- `tradition` は `TRADITIONS`、`themes` は `THEMES` の一覧にある語を使う（新しいテーマが必要なら `THEMES` に追加）

## GitHub Pages で公開する手順

1. [GitHub](https://github.com/) にログインし、右上の「+」→「New repository」
   - Repository name：例 `theologians`（半角英数字）
   - Public を選択し「Create repository」
2. 作成したリポジトリの画面で「uploading an existing file」をクリックし、
   `index.html` と `css` `js` フォルダをまとめてドラッグ＆ドロップ →「Commit changes」
3. リポジトリの「Settings」→ 左メニュー「Pages」
   - Source：`Deploy from a branch`
   - Branch：`main` / `/(root)` を選んで「Save」
4. 1〜2分後、`https://（ユーザー名）.github.io/theologians/` で公開されます

以後の更新は、手順2と同じ方法で変更したファイルをアップロードすれば反映されます。

## 手元で確認するには

`index.html` をダブルクリックすればブラウザで開けます。

## 注意

各項目は簡潔な概要です。年代・書名などは代表的な通説に基づいていますが、研究や説教準備に用いる際は専門の辞典や原典で確認してください。

## メモの同期の設定（Googleアカウント）

メモを端末間で同期するには、無料の Firebase（Google のサービス）を使います。設定は最初に一度だけです。

1. https://console.firebase.google.com/ で「プロジェクトを作成」（名前は例：theologians-notes。Google アナリティクスは不要）
2. 「構築」→「Authentication」→「始める」→「ログイン方法」で **Google** を有効にする
3. 「Authentication」→「設定」→「承認済みドメイン」に **shuichifujii-pastor.github.io** を追加
4. 「構築」→「Firestore Database」→「データベースを作成」（本番環境モード、場所は asia-northeast1 など）
5. Firestore の「ルール」に次を貼り付けて「公開」（ログインした本人だけが自分のメモを読み書きできる）

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{uid}/notes/{noteId} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
  }
}
```

6. プロジェクトの設定（歯車）→「マイアプリ」で **ウェブアプリ（</>）** を追加し、表示された `firebaseConfig` の値を `js/firebase-config.js` の `null` の代わりに貼り付ける
7. `js/firebase-config.js` を GitHub にアップロード

`js/firebase-config.js` が `null` のままなら同期は使わず、メモは各端末のブラウザだけに保存されます。

現在の設定：Firebase プロジェクト **theologians-notes**（Firestore は asia-northeast1／東京、無料の Spark プラン）。
